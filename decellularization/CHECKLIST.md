## Pre-flight

- [ ] IACUC / biosafety coverage confirmed for this tissue
- [ ] Native baseline piece reserved (histology ± DNA/collagen/GAG)
- [ ] Fresh detergent and DNase prepared
- [ ] Waste containers ready for SDS/SDC
- [ ] Labels printed (batch ID on every tube)

## DET (SDS / SDC arms)

- [ ] Cycle 1 complete (water 24 h → detergent 4 h → washes → DNase 3 h)
- [ ] Cycle 2 complete
- [ ] Cycle 3 complete (if used) — actual cycles run: ___
- [ ] ≥ 3 days PBS + 3% P/S rinse with daily changes

## Triton + NH₄OH arm (if used)

- [ ] Water 24 h at 4 °C
- [ ] Optional trypsin–EDTA 1 h at 37 °C + PBS washes
- [ ] 2% Triton X-100 + 0.8% NH₄OH for 72 h at 4 °C with agitation
- [ ] Water washout 48 h with multiple changes
- [ ] PBS ×3, then ≥ 3 days PBS + 3% P/S
- [ ] DNase rescue if DNA/DAPI failed — done ☐ n/a ☐

## QC gate (must pass)

- [ ] dsDNA < 50 ng / mg dry ECM — value: ___ ng/mg — method: ☐ Qubit ☐ other
- [ ] Agarose: fragments < 200 bp or no detectable DNA
- [ ] DAPI: no intact nuclei (core checked)
- [ ] H&E reviewed
- [ ] Laminin and/or collagen I retained (IF or trichrome)
- [ ] sGAG note (required if batch used for FGF2/HSPG work):
- [ ] Cytocompatibility smoke test (if reseeding soon)

## Disposition

- [ ] Live scaffold storage: ☐ PBS+P/S 4 °C ☐ LN2 freezing medium ☐ Immediate use
- [ ] Histology archive (separate aliquot only): ☐ 4% PFA / formalin fixed → PBS / OCT / paraffin
- [ ] Confirmed: fixed pieces will **not** be reseeded
- [ ] Sterile handling plan before culture confirmed
- [ ] Batch ID recorded in lab notebook / digital log
