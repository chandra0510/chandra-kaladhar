# Decellularization — overview

Draft working protocol for producing acellular extracellular-matrix (ECM) scaffolds from:

1. **Fusion-positive ARMS xenograft tissue** (e.g., RH30-derived tumors) — detergent: **1% SDS**
2. **Healthy skeletal muscle** (comparator) — detergent: **4% sodium deoxycholate (SDC)** or, as an alternative when SDC under-clears thick pieces, **1% SDS**

The method is a detergent–enzymatic treatment (DET) cycle adapted from the Padua ARMS / muscle scaffold literature (Pozzobon et al., Methods Mol Biol 2017; Piccoli / Sgro detergent–enzymatic workflows). It is written for immersion + gentle agitation (not vascular perfusion).

## Why this model

Decellularized ARMS ECM keeps native 3D architecture and matrix proteins while removing cells and most DNA. Seeded RMS lines (or PAX3-FOXO1 knockdown / SPOCK3 knockout cells already used in this laboratory) can then be assayed for attachment, spreading, cortical tension, FGF2 capture, and invasion on a tumor-derived or muscle-derived matrix instead of plastic or simplified coatings.

This draft does **not** replace IACUC, biosafety, or institutional SOP approval. Animal work, tumor harvest, and detergent disposal must follow CHLA rules.

## Pass / fail (minimal)

A scaffold batch is acceptable only if **all** of the following hold (Crapo, Gilbert & Badylak, *Biomaterials* 2011):

- **dsDNA < 50 ng per mg dry ECM**
- **No intact nuclei** on DAPI (preferred) and H&E
- **Residual DNA fragments < 200 bp** on agarose gel (when DNA remains detectable)

Plus lab-specific matrix checks: laminin / collagen I immunofluorescence still present; sirius-red collagen and Blyscan sGAG not collapsed to near-zero relative to matched native tissue; scaffold holds together for handling and reseeding.

Items marked **CONFIRM** need a lab decision before the first production run.
